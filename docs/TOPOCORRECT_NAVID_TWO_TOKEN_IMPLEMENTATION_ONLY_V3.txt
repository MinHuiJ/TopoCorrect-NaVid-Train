======================================================================
1. 任务目标
======================================================================

在 NaVid 的 LLM 输入序列中实现且仅实现两个动态连续状态 Token：

1. Topological Spatial State Token（TST）
   符号：z_topo_t
   作用：表示仅由 RGB 历史、当前 RGB 和已执行动作推断的非深度拓扑空间状态。

2. Landmark-aware Navigation State Token（NST）
   符号：z_nav_t
   作用：表示当前视觉轨迹在指令中的执行阶段、landmark 对齐、进展、偏航/停滞和停止准备状态。

两个 Token 都必须：

    每个导航 step 动态生成
    shape = [B, 1, 4096]
    不增加 tokenizer vocabulary
    不改变原始输入序列长度
    不作为文本 prompt
    不直接覆盖动作
    不读取推理期 GT

最终动作仍由：

    NaVid 原 lm_head
    -> 自回归动作文本
    -> 原 agent extract_result()
    -> Habitat 低层动作

======================================================================
2. 设计原则：不是对 NaVid 原 Token 换名字
======================================================================

TST 和 NST 的原始证据来自 NaVid 已有视觉 Token、语言 Token 和动作历史。

但禁止以下伪实现：

    mean pooling
    -> Linear / MLP
    -> 重命名为 TST / NST

如果只做 pooling + MLP，则没有实现本设计。

第一版必须包含：

TST：
    历史视觉节点恢复
    当前视觉摘要
    已执行动作历史编码
    历史节点间视觉相似关系
    时间距离关系
    temporal adjacency
    relation-aware Transformer
    learned topology query

NST：
    原始指令 token 独立输入
    token-level 视觉—指令 cross-attention
    landmark token probability
    landmark-aware attention bias
    TST 条件输入
    动作历史条件输入
    learned navigation query

NaVid 原视觉 Token 是底层视觉证据。
新模块增加的是：

    显式历史关系建模
    显式动作状态建模
    显式视觉—语言对齐
    显式 landmark-aware 状态压缩

======================================================================
3. 已确认的 NaVid / Uni-NaVid 接口约束
======================================================================

已知模型规格：

    LLM hidden size = 4096
    EVA feature dim = 1408
    mm_projector = 1408 -> 4096 -> 4096
    历史帧在 grid:2 下通常每帧 4 个视觉 Token
    当前 Navigation 帧通常保留 64 个视觉 Token
    tokenizer vocabulary size = 32006

原有特殊 Token 审计值：

    <video_special>  = 32000
    </video_special> = 32001
    <image_special>  = 32002
    </image_special> = 32003
    [Navigation]     = 32004
    <image_sep>      = 32005

<image> 不占词表 ID。
它在 tokenizer_image_token() 中转换为：

    IMAGE_TOKEN_INDEX = -200

实现不得仅依赖硬编码 Token ID。
初始化或测试时必须用实际 tokenizer 核对：

    </video_special> == 32001
    [Navigation] == 32004

不一致时必须 RuntimeError，不能静默继续。

======================================================================
4. 最终 Token 插入方案
======================================================================

不新增 -201 / -202 sentinel。
不新增 tokenizer Token。
不增加输入序列长度。

复用两个已有特殊 Token 的 embedding 位置：

1. TST 替换 </video_special> 的 embedding。
2. NST 替换 [Navigation] 的 embedding。

原始多模态序列核心部分：

    历史视觉 Token
    </video_special>
    <image_special>
    当前 64 个视觉 Token
    </image_special>
    [Navigation]
    指令 Token

修改后：

    历史视觉 Token
    TST
    <image_special>
    当前 64 个视觉 Token
    </image_special>
    NST
    指令 Token

TST：

    TST =
        E(</video_special>)
        + tanh(topo_gate) * delta_topo

NST：

    NST =
        E([Navigation])
        + tanh(nav_gate) * delta_nav

要求：

    topo_gate = nn.Parameter(torch.zeros(()))
    nav_gate  = nn.Parameter(torch.zeros(()))

因此：

    use_topocorrect_tokens=False
        -> 完全走原始路径

    use_topocorrect_tokens=True 且 gate=0
        -> embedding 数值等价原始特殊 Token
        -> sequence length 不变
        -> position 分布不变

TST/NST 不允许写入：

    feat_cache
    long_feat_cache

状态模块必须在 Uni-NaVid 的最终 history memory 形成后读取视觉 Token。

======================================================================
5. TST：Topological Spatial State Token
======================================================================

输出：

    z_topo_t: [B, 1, 4096]

输入：

    history_visual_tokens: [B, L_h, 4096]
    history_group_lengths
    current_visual_tokens: [B, 64, 4096]
    action_history: [B, K]
    action_history_mask: [B, K]

TST 禁止读取：

    instruction_ids
    GT pose
    GT heading
    depth
    top-down map
    distance-to-goal
    shortest-path action
    success / SPL
    oracle stop

----------------------------------------------------------------------
5.1 历史节点恢复
----------------------------------------------------------------------

不能对全部历史 Token 做一次全局均值。

必须按 history_group_lengths 分段：

    history group 1 -> node_1
    history group 2 -> node_2
    ...
    history group M -> node_M

NaVid 常规历史帧通常每组 4 个 Token。
Uni-NaVid 合并后的旧节点可能只有 1 个 Token。
代码必须兼容变长 group。

每组使用：

    masked attention pooling

第一版允许在 attention pooling 不可用时提供 masked mean fallback，
但必须在实现报告中说明。

节点数：

    max_topo_nodes = 64

超出后保留：

    起点节点 1 个
    最近节点 63 个

不得建立跨 episode module 全局 mutable map。

----------------------------------------------------------------------
5.2 当前视觉摘要
----------------------------------------------------------------------

输入：

    current_visual_tokens: [B, 64, 4096]

使用 AttentionPool：

    current_summary: [B, 4096]

投影：

    current_node: [B, 512]

----------------------------------------------------------------------
5.3 动作历史编码
----------------------------------------------------------------------

动作 ID：

    PAD=0
    START=1
    STOP=2
    FORWARD=3
    LEFT=4
    RIGHT=5

默认：

    max_action_history = 32
    action_embedding_dim = 128

第一版固定使用：

    1-layer GRU

输出：

    action_summary: [B, 512]

动作历史只包含真正已执行的动作。
包括从 pending_action_list 中弹出并实际执行的动作。
不包含本次尚未执行的预测动作。

----------------------------------------------------------------------
5.4 节点特征
----------------------------------------------------------------------

每个节点先得到：

    node_visual: [B, 4096]

投影至 512：

    W_visual(node_visual)

加入相对时间特征：

    E_relative_age

加入与当前视觉的关系特征：

    cosine(node_i, current_summary)
    normalized_age
    is_first_node
    is_recent_node

关系标量经 MLP 投影后加入节点表示。

最终：

    x_i: [B, 512]

----------------------------------------------------------------------
5.5 Relation-aware Transformer
----------------------------------------------------------------------

对历史节点 i,j 计算：

    visual_similarity_ij
        = cosine(node_i, node_j)

    temporal_distance_ij
        = abs(i-j) / max(M-1, 1)

    temporal_adjacent_ij
        = 1 if abs(i-j) == 1 else 0

关系向量：

    relation_ij = [
        visual_similarity_ij,
        temporal_distance_ij,
        temporal_adjacent_ij
    ]

RelationMLP 输出：

    relation_bias: [B, 8, M, M]

Attention：

    attention_logits =
        QK^T / sqrt(d)
        + relation_bias

配置：

    state_hidden_size = 512
    topo_layers = 2
    topo_heads = 8
    ffn_dim = 2048
    dropout = 0.1

输入序列：

    [
      learned_topo_query,
      node_1 ... node_M,
      current_node,
      action_summary
    ]

必须为 query/current/action 位置补充合理的 attention bias：
    可使用 0 bias；
    历史节点间使用 relation bias。

取 learned_topo_query 输出：

    h_topo: [B, 512]

投影：

    delta_topo =
        LayerNorm(
            MLP_512_to_4096(h_topo)
        )

最终：

    z_topo_t =
        base_video_end_embedding
        + tanh(topo_gate) * delta_topo

----------------------------------------------------------------------
5.6 第一版 TST 辅助输出
----------------------------------------------------------------------

本轮不训练，但模块 forward 必须返回 logits，供后续训练使用：

    revisit_logits: [B, 1]
    novelty_logits: [B, 1]
    stagnation_logits: [B, 1]

可选：

    repeated_turn_logits
    spatial_progress_logits

本轮只实现 head 和 shape，不生成标签、不计算正式训练损失。

======================================================================
6. NST：Landmark-aware Navigation State Token
======================================================================

输出：

    z_nav_t: [B, 1, 4096]

输入：

    instruction_ids: [B, L_i]
    instruction_attention_mask: [B, L_i]
    current_visual_tokens: [B, 64, 4096]
    action_summary: [B, 512]
    h_topo: [B, 512]

NST 禁止使用：

    人工状态 prompt
    GT instruction progress 作为输入
    GT landmark stage 作为输入
    distance-to-goal 作为输入
    oracle stop 作为输入

----------------------------------------------------------------------
6.1 原始指令独立编码
----------------------------------------------------------------------

instruction_ids 必须只对应原始导航指令。

不得使用整个 Vicuna conversation prompt。
不得依赖固定英文模板切片。
不得在模型内部从 prompt 字符串反向解析指令。

编码：

    instruction_embeds =
        model.embed_tokens(instruction_ids)

投影：

    instruction_hidden =
        W_instruction(instruction_embeds)

shape：

    instruction_hidden: [B, L_i, 512]

----------------------------------------------------------------------
6.2 Landmark Token Head
----------------------------------------------------------------------

必须实现：

    landmark_logits =
        LandmarkTokenHead(instruction_hidden)

shape：

    landmark_logits: [B, L_i]

推理值：

    landmark_prob = sigmoid(landmark_logits)

本轮不生成 landmark 标签，不训练该 head。
但 forward 返回 landmark_logits。

----------------------------------------------------------------------
6.3 导航 Query
----------------------------------------------------------------------

当前视觉：

    current_summary =
        AttentionPool(current_visual_tokens)

构造：

    q_nav =
        learned_nav_query
        + W_current(current_summary)
        + W_topo(h_topo)
        + W_action(action_summary)

shape：

    q_nav: [B, 512]

----------------------------------------------------------------------
6.4 Landmark-aware Instruction Attention
----------------------------------------------------------------------

Q：

    q_nav

K/V：

    instruction_hidden

基础 attention：

    QK^T / sqrt(d)

加入 landmark bias：

    attention_logits =
        QK^T / sqrt(d)
        + landmark_bias_scale
          * log(landmark_prob + eps)

必须应用 instruction_attention_mask。

输出：

    instruction_pointer: [B, L_i]
    instruction_context: [B, 512]

禁止将整句 instruction 直接 mean pooling 作为正式实现。

----------------------------------------------------------------------
6.5 导航状态融合
----------------------------------------------------------------------

使用：

    q_nav
    instruction_context
    h_topo
    action_summary

构造：

    h_nav =
        LayerNorm(
            q_nav
            + instruction_cross_attention
            + FFN(
                concat(
                    q_nav,
                    instruction_context,
                    W_topo(h_topo),
                    W_action(action_summary)
                )
              )
        )

输出：

    h_nav: [B, 512]

投影：

    delta_nav =
        LayerNorm(
            MLP_512_to_4096(h_nav)
        )

最终：

    z_nav_t =
        base_navigation_embedding
        + tanh(nav_gate) * delta_nav

----------------------------------------------------------------------
6.6 第一版 NST 辅助输出
----------------------------------------------------------------------

本轮不训练，但 forward 必须返回：

    progress_logits: [B, 1]
    stop_readiness_logits: [B, 1]
    failure_logits: [B, 8]
    correction_logits: [B, 1]
    recovery_action_logits: [B, 4]
    landmark_logits: [B, L_i]
    instruction_pointer: [B, L_i]

failure 类别顺序固定：

    0 none
    1 drift
    2 wrong_turn
    3 premature_stop
    4 collision
    5 stuck
    6 landmark_miss
    7 other

本轮不实现 loss，不生成训练标签。

8.4 prepare_inputs_labels_for_multimodal()
----------------------------------------------------------------------

必须接收状态输入。

Navigation 分支中：

1. 定位 </video_special>。
2. 核对 Token ID。
3. 用 TST 等长替换其 embedding。
4. 保留 <image_special>。
5. 插入原当前 64 个视觉 Token。
6. 保留 </image_special>。
7. 定位 [Navigation]。
8. 核对 Token ID。
9. 用 NST 等长替换其 embedding。
10. 保留原 instruction embeddings 和 suffix。

必须保证：

    修改前后 sequence length 相同
    attention_mask length 相同
    labels length 相同
    position 分布不因新 Token 增长而改变

TST/NST 为特殊 Token embedding 的残差替换。
不额外添加 IGNORE_INDEX。

8.5 History Group Metadata
----------------------------------------------------------------------

TST 需要 history_group_lengths。

第一版必须在视觉 Token 生成阶段同时产生：

    history_visual_tokens
    history_group_lengths
    current_visual_tokens

不能通过除以 4 猜测所有历史节点。
原因：
    Uni-NaVid 合并节点可能为 1 Token；
    历史 group 长度可变。

如果当前函数只返回扁平 Token：
    修改内部返回结构；
    但必须保持 use_topocorrect_tokens=False 时的外部返回兼容。

推荐内部 dataclass：

    VisualTokenBundle:
        history_tokens
        history_group_lengths
        current_tokens
        original_image_features

9. Agent 接口
======================================================================

reset()：

    self.executed_action_history = []

每次模型 generate 前：

    传入此前已执行动作

每次真正返回 Habitat 动作前：

    将该动作记录为“待执行动作”不够；
    必须明确在调用语义上它将被环境执行。

考虑原 agent 的 act() 返回后环境立即 step，
第一版可在 act() 返回前 append，
但必须确保：
    如果 act() 抛异常，不 append；
    episode reset 清空；
    pending action 也 append；
    stop 也 append。

最近：

    max_action_history = 32

指令单独 tokenize：

    observations["instruction"]["text"]

参数：

    add_special_tokens=False
    truncation=True
    padding 按 batch/collator 需要

不得从完整 prompt 解析指令。

5. 没有动作历史编码。
6. TST 没有 relation bias。

8. NST 没有 landmark-aware bias。
9. 生成 12+6 个状态 Token。
10. 增加 tokenizer vocabulary。
11. 改变原输入序列长度。
12. 使用推理期 GT。
13. 使用状态文本 prompt。
14. 强制覆盖动作。
15. 修改 pending_action_list 的原始决策逻辑。
16. TST 读取指令。
17. NST 不读取 TST。
18. TST/NST 写入 feat_cache。
19. generation 后续解码重复计算状态模块。
20. use_topocorrect_tokens=False 不能恢复 baseline。
21. gate=0 不能恢复 baseline。
22. 擅自启动训练。
23. 擅自运行 16 episode 或完整 Habitat 评测。
